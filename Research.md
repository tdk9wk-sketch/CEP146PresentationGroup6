## What is Droid Deck
- Droid deck is an application translation layer using Proot, Proton, and Fex to bring games made for AMD64 Windows to ARM64 Android devices
- Droid deck is a community driven application licenced as GPL 3.0

## What is Proton
- Proton is a translation layer built off Wine that brings Win32 functionality to Linux

## What is FEX
- Fex is a ARM64 to AMD64 translation layer

## What is Proot
- proot is a sandbox enviroment for another file system that does not require root

## What does Droid Deck do
- Brings the Linux Desktop to Android
- uses the LXQT desktop enviroment
- Brings systemd, glibc, gamescope/wlroots to Android
- Bridges Linux daemons such as PulseAudio
- Translates touchscreen inputs into uinput events
- Translates to native gpu drivers
